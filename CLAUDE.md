# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Neuroscience research codebase for analyzing e-phys neural recordings from the **eTheremin** experiment — a frequency-tracking task comparing neural population activity during **Tracking** (condition=0, animal controls frequency) vs **Playback** (condition=1, frequency is replayed).

## Repository Structure

- **`Modular/`** — GUI-driven pipeline with PySide6 GUI (`gui.py`), reusable library (`src/`), and standalone runner scripts. Uses its own `.venv`.
- **Root `.ipynb` notebooks** — "Group Analysis" exploratory notebooks operating on the same data with parallel utility files (`utils_load_data.py`, `utils_trajectories.py`, `utils_frequency_analysis.py`, `utils_loading.py`).
- **`Felicie/eTheremin_analysis/`** — Animal-specific analyses (TCA, UMAP, bayesian decoding, communication). Has its own copies of utility modules.
- **`Analysis/`** — Peak analysis with own utility copies.
- **`Heatmaps/`** — PSTH plotting and heatmap scripts (`playback.py`, `plot_psth.py`).
- **`wave_clus_python-main/`** — Spike sorting library (external dependency).
- **`weibo_daily_summary.py`** — Unrelated Weibo social media scraper script.

## Modular Pipeline Architecture

### Data Flow
```
Raw .npy files (data_N.npy, features_N.npy, good_clusters.npy)
  → get_cached_or_processed_data() → pickle cache
  → Runner script (extracts events, computes PSTH/Z-scores/statistics)
  → CSV + PNG output in timestamped subdirectory under OUTPUT_DIR
```

### Key Files in `Modular/`

| File | Role |
|------|------|
| `config.py` | **Auto-generated by GUI** — central config with paths, signal params, analysis parameters. All runner scripts import from here. |
| `gui.py` | PySide6 GUI for session selection, parameter configuration, one-click pipeline execution, and result browsing. |
| `src/data_loader.py` | Loads `.npy` files, resolves feature/data path variants, filters by good_clusters, smooths data, caches via pickle. |
| `src/processing.py` | PSTH segment extraction, Z-score computation, chronological chunk extraction. |
| `src/psth.py` | Shared PSTH extraction for multi-analysis support: global, first-N, last-N, transition-anchored. |
| `src/stats.py` | Paired t-tests with FDR correction, ANOVA, pairwise Welch's t-test matrices. |
| `src/plotting.py` | Boxplots with significance brackets, chunk progression plots, pairwise significance heatmaps. |

### Runner Scripts (each is self-contained, runs `main()`)

- `run_expanding_n.py` — First n Tracking vs Last n Playback comparisons across blocks
- `run_chronological_chunks.py` — Chronological chunk boxplots + heatmaps
- `run_psth.py` — Per-block and global PSTH plots
- `run_first_last_block.py` — First vs last block PSTH comparisons
- `run_psth_matrix.py` — PSTH matrix (Block × N values)
- `run_transition_psth.py` — Transition-anchored PSTH (TR→PB block pairs)
- `run_trigger_stats.py` — Trigger event statistics and session diagnostics
- `run_session_diagnostics.py` — Session-level quality checks

### How to Run
```bash
# GUI mode
cd Modular && python gui.py

# Or run individual analysis via GUI (it spawns subprocesses)
# Or run a single analysis directly (reads config.py):
cd Modular && python run_psth.py
```

## Data Format

- **Neural data** (`data_<dt>.npy`): 2D array (neurons × time bins)
- **Feature data** (`features_<dt>.npy`): DataFrame/list with columns `Played_frequency`, `Condition` (0=TR, 1=PB), `Block`, `Frequency_changes` (boolean event marker), `Mock_frequency`, `Mock_change`
- **Good clusters** (`good_clusters.npy`): 1D array of neuron indices to keep
- **dt**: Bin size in seconds (typically 0.005s)

## Key Parameters (in config.py)

- `DT` = 0.005 (bin size, seconds)
- `T_PRE` / `T_POST` = 0.3 (PSTH window around events)
- `BASELINE_BINS` = 0.2s before trigger; `IDX_PEAK_START` to `IDX_PEAK_END` = 0 to 0.3s after trigger
- `N_VALUES` = [1, 2, 4, 8, 16, 32, 64, 128, 256] (expanding N)

## Dependencies

Core: `numpy`, `pandas`, `scipy`, `matplotlib` (Agg backend for headless), `seaborn`, `statsmodels`, `scikit-learn`, `tqdm`. GUI: `PySide6`. Notebook extras: `jupyter`, `umap-learn`, `xarray`.

## Important Conventions

1. **`config.py` is auto-generated** by the GUI — never edit it manually. It is overwritten on each GUI run.
2. **Matplotlib uses `Agg` backend** — all plotting scripts set `matplotlib.use('Agg')` for headless operation.
3. **Output is organized by timestamped run directories** under `OUTPUT_DIR` (e.g., `PSTH_20260316_120000/`).
4. **Data is cached** via pickle at `CACHE_PATH`. Delete the cache file to force reprocessing from raw `.npy` files.
5. **Utility files are duplicated** across root, `Analysis/`, and `Felicie/` directories. Changes in one location may need propagation to others.
